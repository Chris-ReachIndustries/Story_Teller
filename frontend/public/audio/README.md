# Ambient Music

This folder should contain the ambient lo-fi music file for the waiting states.

## Required File

- `ambient-lofi.mp3` - A lo-fi/chill instrumental track (2-3 minutes, loops well)

## Where to Get Royalty-Free Music

1. **Free Music Archive (CC0)**: https://freemusicarchive.org/music/holiznacc0/lo-fi-and-chill
   - Recommended tracks: "Morning Coffee", "Clouds", "Plants.mp3"
   - License: CC0 (completely free to use)

2. **Pixabay**: https://pixabay.com/music/search/lofi%20chill%20ambient/
   - Search for "lofi chill ambient"
   - All tracks are royalty-free

## File Requirements

- Format: MP3
- Size: 2-4 MB recommended
- Duration: 2-3 minutes (will loop automatically)
- Style: Mellow, instrumental, no vocals

## After Adding the File

The ambient music will automatically:
- Fade in when players are waiting on others
- Fade out when it's the player's turn to act
- Remember mute preference across sessions
